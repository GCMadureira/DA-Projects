# DA Second Project

This project focus on an optimization problem, the Knapsack problem. It implements 6 different methods to solve this problem, presenting the solution and, when applicable, if its optimal. It furthermore includes a benchmark program to measure the performance of each solution (better with the largest datasets).

## Running

To compile and run the program, use the following commands:

```bash
# in the project's root directory
$ cd build
$ cmake ..
$ cmake --build .
$ ./Project2

=== Select Mode ===
1. Normal Use (Interactive)
2. Run Automated Benchmark Tests
0. Exit
Choice: 
```
