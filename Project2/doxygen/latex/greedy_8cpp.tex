Solves the pallet packing problem using a greedy approach. 

Selects pallets based on increasing weight-\/to-\/profit ratio until the truck is full or no more pallets fit. To do so it sorts all the pallets based on said ratio first and iterates through the sorted vector. Has an O(n\texorpdfstring{$\ast$}{*}log(n)) time complexity since it sorts all the pallets once, and an O(n) space complexity since it uses a vector to store the sorted pallets.
