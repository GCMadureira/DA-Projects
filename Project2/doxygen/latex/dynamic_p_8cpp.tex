\mbox{\hyperlink{struct_knapsack_result}{Knapsack\+Result}} dp\+\_\+approach (\begin{DoxyParamCaption}\item[{const \mbox{\hyperlink{struct_problem_instance}{Problem\+Instance}} \&}]{instance}{}\end{DoxyParamCaption})}



Solves the pallet packing problem using a dynamic programming approach. 

Uses a bottom-\/up method to compute the optimal combination of pallets for maximum profit. Depending on the truck capacity or dataset size, it dynamically chooses between using a vector-\/based or unordered\+\_\+map-\/based DP table for performance efficiency. Using the vector based approach, it has an O(n\texorpdfstring{$\ast$}{*}\+W) time complexity since it iterates through all n pallets, and for each it processes (W -\/ pallet.\+weight) weights, and an O(n\texorpdfstring{$\ast$}{*}\+W) space complexity since it uses a vector of size W+1 containing other vectors with size of at most n. Using the hash map based approach, it has an O(n\texorpdfstring{$\ast$}{*}k) time complexity and an O(n\texorpdfstring{$\ast$}{*}k) space complexity for the same reasons as the vector based approach, except k is the number of reachable unique weights, which is generally way smaller than C.
