Solves the pallet packing problem using a brute-\/force backtracking approach. 

Explores all possible combinations of pallets to find the maximum profit without exceeding the truck\textquotesingle{}s capacity. Uses a backtracking approach without bounding, effectively exploring all the branches/combinations. Has an O(2\texorpdfstring{$^\wedge$}{\string^}n) time complexity since it always explores all possible combinations, and an O(n) space complexity since it only needs to store 2 vectors of size n and a constant number of variables.
