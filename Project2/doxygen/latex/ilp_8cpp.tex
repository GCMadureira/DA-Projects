\mbox{\hyperlink{struct_knapsack_result}{Knapsack\+Result}} ilp\+\_\+approach (\begin{DoxyParamCaption}\item[{const \mbox{\hyperlink{struct_problem_instance}{Problem\+Instance}} \&}]{instance}{}\end{DoxyParamCaption})}



Solves the pallet packing problem using an integer linear programming approach. 

Each pallet is converted to a binary variable, that is, it only has values \texorpdfstring{$<$}{<}=0 or \texorpdfstring{$>$}{>}=1. The objective function is the sum of the variables multiplied by the profit of the pallet that it originated from. This way, if a variable is set to 1, it means the pallet is selected and is contributing to the objective function. The only starting constraint is one where the sum of all the variables, each times the weight of the pallet of origin, is less or equal to the truck capacity. Has an O(2\texorpdfstring{$^\wedge$}{\string^}n) time complexity in the worst case, since it needs to explore an exponential number of nodes (it is an NP problem), but in the average case is much more efficient. Has an O(n) space complexity where n is the number of variables (pallets) and m is the number of constraints needed.
