◆ receiveInput()

void receiveInput ( int choice)

Receives route parameters depending on the route plan.

Calls getValidInt() and getValidList() to receive the input parameters used to execute the algorithm. It always receives the source and destination nodes independent of the route plan chosen, however all the other parameters are choice dependent.
At the end it calls writeInputToFile() passing the parameters received to save them on an input file that can be processed.

Parameters
choice- represents the route type chosen and dictates which parameters will be received

◆ selectMode()

int selectMode ( int choice)

Receives a choice from the terminal to select the mode (manual or batch)

Asks for terminal input until it receives a valid one.

  • if 1 is received then call receiveInput() to ask for the route parameters
  • if 2 is received do nothing since batch mode uses the inputs from a file
  • if 3 is received then return 1 to signal the calling function to not proceed with the algorithm, allowing choice changing
Parameters
choice- represents the route type chosen and is passed to receiveInput()
Returns
0 to proceed with the algorithm execution and 1 otherwise
