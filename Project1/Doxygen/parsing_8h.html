Loads data into a graph.

Then loads the data read into the input graph, skipping invalid edges.

void parseAvoidNodes ( const Graph< int > & graph,
const std::string & avoidNodesLine,
const int startNode,
const int endNode )

Parses and processes the nodes to avoid from the string avoidNodesLine.

Parses the avoidNodesLine with the format AvoidNodes:<id>,<id>,....
If any node has an invalid format, is the same as the startNode or endNode or does not exist in the graph it prints a warning to the terminal.
If a node is valid it sets its ignore flag to true.

Parameters
graph- reference to a graph object containing the nodes to avoid
avoidNodesLine- string reference to the avoid nodes line with format AvoidNodes:<id>,<id>,...
startNode- node from which the route to be processed will start
endNode- node where the route to be processed will end
