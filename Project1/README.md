# DA First Project

This project implements a method of obtainining the best path between two nodes through Djikstra's algorithm. To this end, it has available a CLI that allows the user to choose what type of route should be calculated (with restrictions or not), as well as all the parameters for each execution.

## Running

To compile and run the program, use the following commands:

```bash
# in the src/ directory
$ g++ menu.cpp -o menu
$ ./menu
Graph successfully loaded with 1256 locations and 1881 connections.

===== Route Planning =====
1. Independent Route Planning
2. Restricted Route Planning
3. Environmentally Friendly Route Planning
4. Exit
Enter your choice:
```
