The first project focuses on Dijkstra's algorithm to find the shortest path on a weighted graph, with small variations and restrictions. Provides a CLI to test the datasets available and to set new restrictions. The description of the project can be found [here](./Project1/Project1Description.pdf).

---

The second project focuses on solutions to an optimization problem (resembling the 0/1 knapsack problem). Also provides a CLI to control the program execution, test differents datasets and measure the efficiency of the different available algorithms. The description of the project can be found [here](./Project2/da2425-Project2Description.pdf).
